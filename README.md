# 🎵 51单片机蜂鸣器播放《小星星》

基于 **AT89C52** 单片机的无源蜂鸣器音乐播放项目,使用定时器产生方波驱动蜂鸣器,循环播放经典儿歌《小星星》。

## ✨ 功能特性

- 🎼 定时器中断精确控制音高,支持完整音阶(do~si)
- 🔁 循环播放整首曲子,曲间自动停顿
- 📝 曲谱与音符数据分离,修改歌曲只需改两个数组
- 🛠️ 提供 Keil4/Keil5 双版本工程文件,开箱即用
- 🔬 支持 Proteus 仿真验证

## 🔧 硬件需求

| 器件 | 说明 |
|------|------|
| 单片机 | AT89C52 / STC89C52 |
| 晶振 | 12MHz |
| 蜂鸣器 | **无源**蜂鸣器(需方波驱动) |
| 驱动 | 8550 或 8050 三极管 + 1kΩ 基极电阻 |

## 🔌 接线示意

```
AT89C52 P2.0 ──[1kΩ]──>| 8550 三极管 (B 极)
                            E 极 → VCC (5V)
                            C 极 → 蜂鸣器负极
                                   蜂鸣器正极 → VCC
```

> ⚠️ 注意:必须使用**无源蜂鸣器**,有源蜂鸣器无法通过改变频率演奏音乐。

## 🚀 使用方法

### 1. Keil 编译

1. 用 Keil uVision 打开 `twinkle.uvproj`(Keil4)或 `twinkle_Keil5.uvprojx`(Keil5)
2. 按 **F7** 编译,看到 `0 Error(s)` 即成功
3. 自动生成 `Output/twinkle.hex`

### 2. 烧录运行

- 用 STC-ISP 等工具将 `twinkle.hex` 烧录到单片机开发板
- 或使用 Proteus 加载 hex 进行仿真

## 🎼 修改歌曲

只需修改 `twinkle.c` 中的两个数组:

```c
// 音符数组:1~7 对应 do~si,0 为休止符
code uchar song[] = {1,1,5,5,6,6,5, ...};

// 节拍数组:与音符一一对应,数值 = 拍数
code uchar beat[] = {1,1,1,1,1,1,2, ...};
```

**示例——换成《两只老虎》**:

```c
code uchar song[] = {1,2,3,1, 1,2,3,1, 3,4,5, 3,4,5,
                     5,6,5,4,3,1, 5,6,5,4,3,1, 2,5,1, 2,5,1};
```

**调整整体播放速度**:修改 `main()` 中的拍长(单位 ms):

```c
play_tone(freq[song[i]], beat[i] * 350);  // 350ms/拍
```

| 频率(Hz) | 523 | 587 | 659 | 698 | 784 | 880 | 988 |

## 📖 实现原理

1. **音高控制**:定时器 T0 工作在方式 1,按音符频率的半周期翻转 IO 电平,产生对应频率的方波
2. **频率计算**:12MHz 晶振下机器周期 1μs,定时初值 = 65536 − 500000/频率
3. **节拍控制**:每个音符持续 `拍数 × 拍长` 毫秒后切换到下一个音符
